# EAS Project Charter

## Project Name
EAS (AI Product Sourcing System)

## Vision
Build an AI-powered product sourcing system that automatically discovers profitable products for resale.

## Phase 1 Goal
Costco Online → Coupang AI Sourcing

## Core Workflow

1. Collect products from Costco Online
2. Normalize product information
3. Search identical or similar products on Coupang
4. Estimate selling price
5. Calculate fees
6. Calculate expected net profit
7. Analyze selling risks
8. Recommend:
   - Buy
   - Hold
   - Skip

## Future Roadmap

- Multiple suppliers
- Automatic price monitoring
- Inventory management
- AI listing generation
- Sales analytics
- Learning recommendation engine
